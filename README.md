# 🐾 Mimie's Pet Hub

A complete pet marketplace web application for buying, selling, and reporting pets in Zimbabwe.

## 📋 Features

- **Pet Listings** - Browse pets available for sale
- **Shopping Cart** - Add pets to cart and checkout
- **Payment Methods** - EcoCash, InnBucks, Bank Transfer, Card, Cash on Delivery
- **Sell Pets** - Users can list their pets for sale
- **Lost & Found** - Report lost or found pets
- **Homeless Reports** - Report homeless pets
- **Admin Panel** - Manage pets, users, reports, and sales
- **Email Notifications** - Order confirmations and updates
- **Responsive Design** - Works on desktop and mobile

## 🛠️ Technology Stack

- **Backend:** PHP 8.2
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Styling:** Google Fonts (Poppins), Font Awesome
- **Payment Gateway:** PayNow (Zimbabwe)
- **Server:** XAMPP/Apache

## 📁 Database Setup

1. Import `database.sql` into phpMyAdmin
2. Update `includes/config.example.php` with your database credentials
3. Rename `config.example.php` to `config.php`
